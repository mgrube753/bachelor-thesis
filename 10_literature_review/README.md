# Literature Review

Here, the systematic literature review conducted is presented.

## Structure

### Review Criteria and Methodology
- **[`10_counts_criteria/`](10_counts_criteria/)** - Literature selection criteria and paper counts
    - [`criteria.md`](10_counts_criteria/criteria.md) - Inclusion/exclusion criteria using TACID method
    - [`counts.md`](10_counts_criteria/counts.md) - Amount of papers taken from each prompt and database

### Search Queries and Prompts
- **[`20_queries_prompts/`](20_queries_prompts/)** - Search strategies and database queries
  - [`10_llms/`](20_queries_prompts/10_llms/) - Large Language Model focused searches
  - [`20_llms_evaluation/`](20_queries_prompts/20_llms_evaluation/) - LLM evaluation methodology searches
  - [`30_llms_questions_bloom/`](20_queries_prompts/30_llms_questions_bloom/) - Bloom's Taxonomy alignment searches

### Bibliography Collections
- **[`30_bib_files/`](30_bib_files/)** - Organized bibliography files after literature review:
  - [`Positive.bib`](30_bib_files/Positive.bib) - Relevant papers from the literature review
  - [`Extras.bib`](30_bib_files/Extras.bib) - Supporting papers cited in positive papers
  - [`Eigenes.bib`](30_bib_files/Eigenes.bib) - Self-discovered papers through independent search

## Search Tools and Databases

- **Google Scholar**: Comprehensive academic paper discovery
- **Elicit**: AI-powered research assistant for targeted queries
- **Zotero**: Reference management and PDF organization
