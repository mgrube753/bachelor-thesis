# Literature Review

This directory presents the systematic literature review conducted for the thesis.

## Structure

### Review Criteria and Methodology

- **[`10_counts_criteria/`](10_counts_criteria/)**: Contains literature selection criteria and paper counts.
    - [`criteria.md`](10_counts_criteria/criteria.md): Inclusion/exclusion criteria using the TACID method.
    - [`counts.md`](10_counts_criteria/counts.md): Number of papers selected from each prompt and database.

### Search Queries and Prompts

- **[`20_queries_prompts/`](20_queries_prompts/)**: Search strategies and database queries.
  - [`10_llms/`](20_queries_prompts/10_llms/): LLM-focused search queries.
  - [`20_llms_evaluation/`](20_queries_prompts/20_llms_evaluation/): Queries for LLM evaluation methodologies.
  - [`30_llms_questions_bloom/`](20_queries_prompts/30_llms_questions_bloom/): Queries related to Bloom's Taxonomy alignment.

### Bibliography Collections

- **[`30_bib_files/`](30_bib_files/)**: Organized bibliography files from the literature review.
  - [`Positive.bib`](30_bib_files/Positive.bib): Relevant papers identified.
  - [`Extras.bib`](30_bib_files/Extras.bib): Supporting papers cited in positive papers.
  - [`Eigenes.bib`](30_bib_files/Eigenes.bib): Independently discovered papers.

## Search Tools and Databases

- **Google Scholar**: Comprehensive academic paper discovery
- **Elicit**: AI-powered research assistant for targeted queries
- **Zotero**: Reference management and PDF organization
