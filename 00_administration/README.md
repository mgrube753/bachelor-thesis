# Administration

This directory contains all administrative documents and project management materials for the bachelor thesis "Generating Educational Questions using Large Language Models: An Evaluation of Quality and Alignment with Pedagogical Principles".

## Contents

- **concept.tex** / **concept.pdf**: LaTeX source and compiled concept document outlining research objectives, methodology, and planned approach.
- **Expose_Malte-Grube.pdf**: Thesis exposé for official submission.
- Other LaTeX auxiliary files for compilation.

## Overview

The concept document and especially the exposé detail the research questions, experimental design, and evaluation strategies for assessing LLM-generated educational questions, focusing on:

1. Content adherence and error detection in LLM-generated questions
2. The relationship between question formats and Bloom's Taxonomy levels
3. Pedagogical effectiveness and evaluation methodologies
