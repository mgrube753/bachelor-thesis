# Administration

This directory contains administrative documents and project management materials for the bachelor thesis "Generating Educational Questions using Large Language Models: An Evaluation of Quality and Alignment with Pedagogical Principles".

## Concept Documents

- **concept.tex** - LaTeX source file for concept document
- **concept.pdf** - Compiled concept document
- **Expose_Malte-Grube.pdf** - Thesis exposé for application

## Document Overview

The concept documents outline the research objectives, methodology, and planned approach for evaluating Large Language Model capabilities in generating educational questions aligned with Bloom's Taxonomy. Key research questions address:

1. Content adherence and error detection in LLM-generated questions
2. Relationship between question formats and Bloom's Taxonomy levels
3. Pedagogical effectiveness evaluation methodologies
