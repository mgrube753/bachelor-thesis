# Documentation

This directory shows the technical documentation and implementation guides for the bachelor thesis project.

## Purpose

The documentation directory offers:

- **API Usage Guides** - Instructions for integrating with LLM providers (OpenAI, Anthropic, Google, DeepSeek)
- **Code Documentation** - Detailed explanations of experimental scripts and data processing pipelines
- **Setup Instructions** - Environment configuration and dependency management
- **Analysis Workflows** - Step-by-step guides for quantitative and qualitative evaluation procedures
