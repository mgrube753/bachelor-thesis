The first experiment of the thesis focused on evaluating the content fidelity of questions generated by different \ac{llms} using two distinct prompt strategies: a common prompt and a complex prompt. In this experiment, the goal was to determine whether the complexity of the prompt influences the content fidelity and final scoring of the generated questions, addressed in the first research question:

\requ{1}{To what extent do \ac{llms} adhere to the content of diverse provided instructional texts when generating questions?}

\object{Quantitative Analysis} semantic sim via cossim vs. llm-based content adherence calculation, there are tables and plots needed.

\section*{Experiment 1a}

\begin{itemize}
    \item question type was not fixed, but via format constraints limited to either Open-Ended or MC questions. trend towards mc questions, open ended is exp1a 9/168 (only complex prompt, 8x openai, 1x google), exp1b 4/56 questions (1x common prompt deepseek, 3x google). % #TODO maybe also add here the table 1 from intermed
    \item my way is a bit different from plans in literature, since source texts and llm outputs differ much. \cite{li_planning_2024} used bertscore for semantic similarity scoring, but between generated and ground truth q-a pairs. by this, the cossim results in exp1a are less comparable.
    \item besides the input sources, the llms were prompted for each layer without using an input source as well. every q-a pair was then compared to every input source, shown in Figure \bfref{fig:exp1a-source-scores}. the cosine similarity unfortunately does not show significant trends as the adherence scores do; in adherence score we see that using no source has a proper impact on the score set at least. the current cossim trend in the sources is that script is shortest, tanenbaum medium and transcript is longest, so the scorings are descending in cossim script > tanenbaum > transcript. 
    \item nosource shows that cossim can not be used to determine if a model follows the source material, which is not only a sentence.
    \item cossim via sources plot: input sources vs no source... pretty similar trend even though no source was used in the other case.
    \item adherence score shows scattering with respect to input sources; adherence score looks more reliable since llms are spreading way more.
    \item adherence: anthropic and google struggle with minor less scores (also watch std for both), deepseek and openai are more consistent.
    \item konsequente kontextgebung etwa gleicher laenge und wenig davon (max. 30 woerter) kann für logischere ergebnisse bei cossim sorgen. in diesem fall muss cossim discarded werden 
\end{itemize}

\section*{Experiment 1b}

\begin{itemize}
    \item adherence score ausgabe: bei bewertung ist anthropic oft unnötig höher als openai
    \item in exp1b, cossim cannot detect if an llm follows the manipulated content or llm detects it (tells this somehow and then generates question based on that text (oder frage wie zitate unten)). since the cossim in exp1a was not that reliable, and the cossim is high in 1b (???), it is not reliable and shall be overall discarded.
    \item mixed outcomes in adherence scores.
    \item grundsaetzlich folgen die modelle ueberaus dem manipulierten content, tiefe werte sind zurecht dort unten vertreten, grundsaetzlich logisches bild in 1b adherence
    \item DeepSeek hat es oft erkannt und somit median und mean nach unten gezogen; anthropic und google aehnlich zueinander. openai folgt auch sehr dem content, verzeichnet aber tieferen mean durch erkennungs-outliers. DeepSeek erkennbar \enquote{besser}
    \item auch im common prompt ist deepseek klar tiefer als die anderen, da gelegentlich auch fragen kommen, wie \enquote{Welche der folgenden Aussagen beschreibt eine echte Kernaufgabe des Data Link Layers im ISO-OSI-Modell, basierend auf korrektem Fachwissen?}, oder \enquote{Welche Eigenschaft wird dem Transport Layer laut Beschreibung NICHT zugeordnet?}
    \item complex prompt folgert dass die modelle den manipulierten content besser infragestellen!! dass cossim leicht aehnliches zeigt ist aber nicht von bedeutung
\end{itemize}

The goal of this was to determine how different question formats, Multiple-Choice and Open-Ended questions, perform across various cognitive levels of Bloom's revised Taxonomy. This experiment dealt with the second research question:

\requ{2}{How does the relationship between diverse question formats and Bloom's Taxonomy levels influence the pedagogical effectiveness of \ac{llm}-generated questions?}
