Frage: Im gegebenen Text werden drei Kernaufgaben der Session Layer (Schicht 5) des OSI-Modells beschrieben. Wenn man diese Beschreibung mit dem standardmäßigen OSI-Referenzmodell vergleicht, welche der folgenden Aussagen ist korrekt?

Antwortmöglichkeiten:
- Die beschriebenen Eigenschaften (Datagramme, Asynchronität, Atomisierung) entsprechen nicht der klassischen Definition der Session Layer, sondern eher Funktionen niedrigerer Schichten wie der Transport Layer (4) oder Network Layer (3) (Richtig)
- Die Session Layer hat laut OSI-Standard tatsächlich genau die drei beschriebenen Kernaufgaben als Hauptfunktionen (Falsch)
- Die beschriebene Atomisierung von Datenpaketen ist eine korrekte Hauptfunktion der Session Layer, während Datagramme und Asynchronität eigentlich zur Presentation Layer (6) gehören (Falsch)
- Die Session Layer ist gemäß OSI-Modell ausschließlich für verbindungslosen Datenaustausch konzipiert, wie im Text korrekt beschrieben (Falsch)
