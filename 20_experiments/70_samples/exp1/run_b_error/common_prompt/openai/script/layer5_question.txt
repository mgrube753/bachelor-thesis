Frage: Welche der folgenden Kernaufgaben gehören laut Beschreibung zur Session Layer (Schicht 5) des ISO-OSI-Modells?

Antwortmöglichkeiten:
- Datagramme: spontanes Erstellen, Senden, Empfangen und sofortiges Verwerfen (Richtig)
- Asynchronität: Vermeidung von Zwischenpunkten und Bestätigungen (Richtig)
- Atomisierung: Aufspaltung unabhängiger Datenpakete in Einzelteile (Richtig)
- Adressierung von Endgeräten im Netz (Falsch)
- Bitübertragung über das physische Medium (Falsch)
- Verschlüsselung auf Anwendungsebene (Falsch)
