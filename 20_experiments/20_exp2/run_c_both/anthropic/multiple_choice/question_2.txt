Frage: Vergleichen Sie die Flusssteuerung in verschiedenen Schichten des OSI-Modells. Welche Aussage beschreibt korrekt den Unterschied zwischen der Flusssteuerung im Data Link Layer und der Flusssteuerung im Network Layer?

Antwortmöglichkeiten:
a) Die Flusssteuerung im Data Link Layer betrifft die Kommunikation zwischen direkt verbundenen Geräten, während die Flusssteuerung im Network Layer sowohl End-to-End (Sender zum entfernten Empfänger) als auch Node-to-Node (von jedem Knoten zum Nächsten) umfasst. (Richtig)
b) Die Flusssteuerung im Data Link Layer ist ausschließlich für die Komprimierung von Daten zuständig, während die Flusssteuerung im Network Layer die Verschlüsselung der Daten regelt. (Falsch)
c) Die Flusssteuerung im Network Layer wird nur zwischen Geräten im selben Netzwerk eingesetzt, während die Flusssteuerung im Data Link Layer netzwerkübergreifend funktioniert. (Falsch)
d) Die Flusssteuerung im Data Link Layer befasst sich mit der Quality of Service, während die Flusssteuerung im Network Layer sich ausschließlich mit der Adressierung beschäftigt. (Falsch)
