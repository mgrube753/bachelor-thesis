Frage: Welche der folgenden Aufgaben gehören zu den Kernaufgaben der Presentation Layer (Schicht 6) im ISO-OSI-Modell?

Antwortmöglichkeiten:
- Vereinheitlichung der Datendarstellung (Richtig)
- Behandlung von Binärdaten ohne Zeichendarstellung (Richtig)
- Entpacken komprimierter Daten (Richtig)
- Entschlüsseln von Daten (Richtig)
- Bestimmung des optimalen Übertragungswegs (Falsch)
- Sicherstellung einer fehlerfreien Bitübertragung (Falsch)
- Bereitstellung von Ende-zu-Ende-Verbindungen (Falsch)
