Frage: Welche der folgenden Funktionen gehören laut Text zu den Kernaufgaben der Network Layer (Schicht 3) im ISO-OSI-Modell?

Antwortmöglichkeiten:
- Lokalisierung innerhalb des Netzwerks (Richtig)
- Zufällige Pfadauswahl zwischen Endknoten (Zufallspfad) (Richtig)
- Datenbeschleunigung bei zu langsamer Übertragung (Richtig)
- Kryptografische Verschlüsselung der Daten (Falsch)
- Aufbau von Anwendungssitzungen (Falsch)
