Frage: Gemäß dem bereitgestellten Text, welche der folgenden Aussagen beschreibt *nicht* eine Kernaufgabe der Presentation Layer (Schicht 6) des ISO-OSI-Modells?

Antwortmöglichkeiten:
- Die Vereinheitlichung der Datendarstellung, wie z.B. die Festlegung auf ein einziges Serialisierungs-Format. (Falsch)
- Das Anbieten von Verschlüsselungsdiensten für die Datenübertragung. (Richtig)
- Das ausschließliche Entpacken von Daten (Expansion). (Falsch)
- Die Behandlung von Daten als reine Binärdaten, ohne Unterscheidung von Zeichendarstellungen wie ASCII oder Unicode. (Falsch)
