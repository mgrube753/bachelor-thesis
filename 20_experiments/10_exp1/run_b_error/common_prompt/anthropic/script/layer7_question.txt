Frage: Welche der folgenden Aussagen beschreiben korrekt die Kernaufgaben des Application Layers (Schicht 7) im ISO-OSI-Modell?

Antwortmöglichkeiten:
- Die Definition universeller Begriffe, die für alle Anwendungen gültig sind (Richtig)
- Die Identifikation von Standardanforderungen und generischen Datenstrukturen (Richtig)
- Die Festlegung von Standardreaktionen des Systems auf generische Anforderungen (Richtig)
- Die physikalische Übertragung von Bits über das Netzwerkmedium (Falsch)
- Die Bereitstellung von Ende-zu-Ende-Verbindungen zwischen Netzwerkknoten (Falsch)
- Die direkte Implementierung anwendungsspezifischer Funktionalitäten ohne Abstraktion (Falsch)
- Die Abstraktion spezifischer Anwendungselemente zu generischen Funktionen (Richtig)
