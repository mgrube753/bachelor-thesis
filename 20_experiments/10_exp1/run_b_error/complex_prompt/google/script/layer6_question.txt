Frage: Die Beschreibung der Presentation Layer (Schicht 6) im OSI-Modell hebt hervor, dass sie bei den Kernaufgaben "Expansion" und "Offenlegung" jeweils nur das Entpacken bzw. Entschlüsseln vornimmt, aber keine gegenläufigen Operationen (Packen oder Verschlüsseln) anbietet. Welche begründeten Implikationen ergeben sich aus dieser asymmetrischen Aufgabenverteilung für die Verarbeitung und den Fluss von Daten im Kontext des OSI-Modells?

Antwortmöglichkeiten:
- Diese Asymmetrie stellt sicher, dass die Presentation Layer ausschließlich für die Vorbereitung empfangener Daten für die obere Schicht zuständig ist, während die entsprechenden Sendeoperationen (Packen, Verschlüsseln) auf der sendenden Seite in einer anderen Schicht, typischerweise der Application Layer oder einer dedizierten Sicherheitsschicht oberhalb der Presentation Layer, angesiedelt sind. (Richtig)
- Die fehlende Funktionalität zum Packen oder Verschlüsseln in der Presentation Layer bedeutet, dass diese Aufgaben vollständig vom Betriebssystem des Endgeräts übernommen werden, bevor die Daten das OSI-Modell betreten. (Falsch)
- Die asymmetrische Definition ist ein Designfehler im OSI-Modell, da jede Schicht sowohl Sende- als auch Empfangsfunktionen für ihre spezifischen Aufgaben bereitstellen sollte, um Symmetrie zu gewährleisten. (Falsch)
- Sie impliziert, dass Daten immer unkomprimiert und unverschlüsselt von der Session Layer an die Presentation Layer übergeben werden und erst danach durch die Application Layer für die Darstellung vorbereitet werden müssen. (Falsch)
- Die Konzentration auf Entpacken und Entschlüsseln unterstreicht die Rolle der Presentation Layer als reine "Datentransformationsschicht", die eingehende Bitströme in ein für die Application Layer verständliches Format überführt und somit die Komplexität der Dateninterpretation von höheren Schichten fernhält. (Richtig)
